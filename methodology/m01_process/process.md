# Process

1. **Plan briefly.** Establish what the task asks for and where in the project_workspace it lands. Keep the
   plan in your head or in your reply; do not write it to a file.
2. **Implement.** Change the smallest set of files that satisfies the task.
3. **Run the tests.** Use the project's own interpreter: `python -m pytest -q`. If the project_workspace ships
   no tests, exercise the code you wrote directly instead.
4. **Stop.** Report what you changed and what the tests said. If something is still failing, say which
   test and why — do not paper over it.

Step 3 is not optional and is not satisfied by reasoning about the code. Run it.
