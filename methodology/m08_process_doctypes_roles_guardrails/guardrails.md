# Guardrails

- Do not create files beyond those the task or this methodology asks for. No README, no notes, no
  scratch scripts.
- Do not modify test files, `conftest.py`, `pytest.ini`, `pyproject.toml`, `.requirements` or
  `.environment`. The tests are the specification, not an obstacle.
- Do not add dependencies. What `.requirements` lists is what you have.
- Read a file completely before editing it.
- Do not refactor code that is not in the way of the task.
- If the task is ambiguous, pick the reading the tests support and state the choice in your answer.
