# Self-review

The work is not finished when the tests pass; it is finished one reading later.

**When the tests are green, stop editing and read the diff.** Every file you changed, in full, in
the order a reviewer would meet it, with the task beside it. You are not re-reading your intention;
you are reading what a stranger would find in the code.

**List what you find before you fix anything.** One line each: the file, the symbol, and what is
wrong. A requirement of the task the diff does not meet, a case the code drops, a name that
promises what the function does not do, a line left behind from an earlier attempt. If the reading
finds nothing, say so and stop.

**Then fix that list, and only that list.** A defect you did not name is a defect for the next
session, not a reason to start reading again.

**One round.** Do not review the fixes, do not hand the diff to another agent and do not spawn
one. The second reading of your own work costs more than it finds.

**State it.** Your answer names how many defects the reading found and how many you fixed.
